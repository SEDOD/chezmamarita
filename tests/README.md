# Tests d'acceptation

Ces scénarios sont écrits avant le code. Ils décrivent le comportement attendu et pourront être traduits en tests automatisés lorsque l'implémentation commencera.

- `01-menu.feature` : gestion du menu.
- `02-commande.feature` : commande par table.
- `03-cuisine.feature` : transmission et statuts cuisine.
- `04-encaissement.feature` : facture et clôture.
- `05-tableau-de-bord.feature` : indicateurs du gérant.
